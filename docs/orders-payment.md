# 주문 & 결제 (Orders & Payment)

- **상태 흐름**:
  ```
  결제대기 → 결제완료 → 배송준비 → 배송중 → 배송완료
                ↓ (PG 실패)
             결제실패
  ```
- **취소 조건**: `결제완료` 상태에서만 즉시 취소 가능 (전액 취소만 지원, 부분 취소 미지원)
  - `배송준비` 이후는 반품 절차로 처리 (cs.md 참고)
- **환불 처리**: 취소 확정 후 영업일 기준 3~5일 이내 원결제 수단으로 환불
  - 포인트 사용 후 취소 시: 사용 포인트 즉시 복원, 차액만 원결제 수단 환불

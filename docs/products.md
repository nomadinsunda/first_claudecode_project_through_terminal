# 상품 (Products)

- **카테고리 구조**: 대분류(`petType`: 강아지/고양이/공용) → 중분류(사료/간식/영양제/장난감/의류/위생용품)
  - `petType` 필드는 대분류 카테고리와 동일한 개념으로 통일하여 사용
- **필수 정보**: `price`(정가), `discountRate`(할인율 %), `stock`(재고), `petType`(대상 동물)
- **할인가 계산**: `salePrice = price × (1 - discountRate / 100)`, 원 단위 절사
- **품절 처리**: `stock === 0`이면 '품절' 배지 표시 및 장바구니 담기 비활성화
- **재고 부족**: 장바구니 수량이 현재 `stock`을 초과할 경우 "재고 N개 남음" 안내 후 수량 자동 조정

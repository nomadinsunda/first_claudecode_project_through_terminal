# 리뷰 (Reviews)

- **작성 권한**: 주문 상태 `배송완료` 전환 후 30일 이내, 실구매자 1인 1주문당 1회
- **포인트 보상**: 관리자 승인 후 적립 (일반 리뷰 500P, 사진/영상 포함 리뷰 1,000P)
- **수정/삭제**: 작성자 본인만 가능, 삭제 시 지급된 포인트 회수

## 리뷰 데이터 구조

| 필드 | 설명 |
|---|---|
| `author` | 닉네임 (마스킹) |
| `petInfo` | `{ name, breed, age }` — 닉네임 옆에 반려동물 정보 표시 |
| `rating` | 1~5 별점 |
| `hasMedia` | 사진/영상 첨부 여부 |
| `images` | 첨부 이미지 URL 배열 |
| `summary` | 한 줄 요약 |
| `content` | 상세 리뷰 본문 |
| `orderedOption` | 구매 상품명 / 수량 |
| `tags` | `longterm` (한달사용기) 등 분류 태그 |
| `helpfulCount` | 도움이 돼요 카운트 |

## 리뷰 목록 UI (ReviewContainer)

- **정렬**: 베스트순(helpfulCount) / 최신순 / 별점 높은순 / 별점 낮은순
- **필터 칩**: 사진 리뷰만 보기 / 한달사용기(`tags: longterm`)
- **키워드 검색**: content 및 summary 대상 클라이언트 사이드 검색
- **페이지네이션**: 5개씩 더보기 (클라이언트 사이드)
- **도움이 돼요**: `POST /reviews/:id/helpful`, 1회 클릭 후 비활성화 (세션 내 중복 방지)
- **라이트박스**: 이미지 클릭 시 전체화면 모달, 이전/다음 네비게이션
- **요약 통계**: 평균 평점 · 별점 분포 프로그레스 바 · 포토 썸네일 가로 스크롤
